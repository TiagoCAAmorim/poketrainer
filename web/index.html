Decks

  

  
Cole uma lista exportada do Pokémon TCG Live ou da Limitless (ex.: 3 Dragapult ex TWM 130). Novos decks vão para decks/meus/. Para baixar top 8 de torneios: python import_limitless.py import --latest 5.

  
  

  





  
Reproduzir partida do Pokémon TCG Live

  
No TCG Live, abra o registro da partida e use Copy Log; cole aqui (inglês ou português). O motor refaz cada jogada, confere os danos com o log oficial e mostra onde as regras divergem.
